= Starting an automated migration report with an RVTools file

[role="_abstract"]
Use this path when you can create an automated report from a supported RVTools export in the {OMA} console, and you have permission to create that file in vSphere and upload it.

[NOTE]
====
For a hands-on Arcade demo of this flow, see link:https://interact.redhat.com/share/pkPLJELVr45LbdXg3InF[Evaluate VMware migration-readiness with the OpenShift migration advisor].
====

.Prerequisites

* You have completed the prerequisites for using an automated migration report, and you can generate a supported RVTools file format and version. The service rejects unsupported formats.

.Procedure

. In the {HCC}, sign in with your {RH} account and open the {OMA} or the automated migration report feature.
. Start a new automated migration report and select the RVTools or file-based option if it is available. If the option is missing, your environment or your entitlement might not include this path, or the flow might be renamed.
. On the workstation where you run RVTools, connect to your vSphere environment, refresh the data that you need, and export a spreadsheet in the format that is described by the product help text or validation messages.
. In the {HCC}, click *Upload* or *Choose file* and select your export. Wait until the file passes validation. Fix any errors that are reported in the console, for example, by re-exporting from RVTools or by removing unsupported sheets if instructed.
. Complete the remaining on-screen questions. Accept any consent or privacy notices that are displayed before the automated report is saved or processed. Read these carefully because they are specific to the path that you use and to the region in which the service runs.
. Open the new automated report in the {HCC} and review the status until the result is *Ready* or a similar completed state.
. If errors are displayed, use the in-product help or the messages next to the failure. Do not attach sensitive exports in an email unless your security process provides a secure channel.

.Next steps

* After the automated report is ready, see _Interpreting risks and migration considerations in an automated migration report_ and the other result topics in this guide. If you are considering an agent later for more detailed data, see _How data handling differs between a file upload and an agent_.
