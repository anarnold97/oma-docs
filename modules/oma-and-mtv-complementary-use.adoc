= How the {OMA} relates to {MTV} in a migration program

[role="_abstract"]
The {OMA} and {MTV} have different jobs in a typical program that moves virtual machines from VMware to {OSV}. The {OMA} is for a pre-migration automated migration report and planning view of the estate. {MTV} is the {RH} product line for executing the migration and managing the movement of virtual machines after you have a design and a target cluster that your organization has approved.

* Use the {OMA} when you need a structured inventory and readiness view and planning outputs from an RVTools file in a supported format or assisted agent run, as your build of the product allows.
* Use {MTV} when you are ready to create migration plans and to run cutover in line with the {MTV} product documentation and your own change and security process.

A fully automated handover from a finished result from the {OMA} into a {MTV} plan is not guaranteed in every {RH} offering, OpenShift and {OSV} version, or subscription. Read the product documentation for the {OMA}, {OSV}, and {MTV} for your environment and use only the integrated workflows that are documented by {RH} for your release.
