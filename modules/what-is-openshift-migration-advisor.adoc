= What the {OMA} is

[role="_abstract"]
The {OMA} is a {HCC} service that helps you review a VMware vSphere environment when you are considering {OSV} as a target. The service produces an *automated migration report* from data you provide. The automated report highlights infrastructure and workload information, risk or compatibility signals the product can detect, and planning outputs such as sizing context. It is a planning step. It does not migrate virtual machines by itself.

The {OMA} is implemented with a user experience in the console and with services or optional software that collect or process vSphere information. You do not need to be an {OSV} administrator to start an automated report, but you do need access to your vSphere environment or to RVTools output, according to the path you choose.
